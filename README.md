# SurslideML

This project was created to learn about artificial intelligence, mathematics, and numerical computing.

## Packages

- **SursArray** — Array manipulation and numerical operations.
- **SursMath** — Mathematical operations and algorithms. *(Planned)*
- **SursML** — Machine learning algorithms. *(Planned)*
- **SursNN** — Neural network implementations. *(Planned)*

## Installation

Clone the repository:

```bash
git clone https://github.com/Surslide/surslide_ml.git
cd surslide_ml
```

Install the package:

```bash
python -m pip install .
```

## Usage

```python
import sursarray as surs

arr = surs.Array([1, 2, 3, 4, 5])

print(arr.shape)
print(arr.mean())
```
